# utilidades

Scripts auxiliares autocontenidos (sin rutas absolutas):

- `leer_excel.py` — volcar un `.xlsx` a texto/CSV (usa `openpyxl`).
- `leer_pdf.py` — extraer texto de un `.pdf` (usa `pypdf`/`pdfplumber`).
- `plantilla_latex/` — plantilla base para informes.

> Pendiente de copiar desde el repo de laboratorio (`MIA_LAB_2026`).

Uso del entorno virtual:

```powershell
.venv\Scripts\pip install openpyxl pypdf pdfplumber
```

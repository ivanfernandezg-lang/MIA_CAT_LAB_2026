# Imagotipo

`usach-horizontal.png` (positivo) y `usach-horizontal-blanco.png` (negativo)
son una extracción de trabajo a baja resolución de la plantilla PPT oficial,
incluida solo para que el proyecto compile sin dependencias.

Antes de presentar, reemplazar por los archivos oficiales del ZIP de
imagotipos de https://guiaweb.usach.cl/normas-gráficas y apuntar el tema:

    \usachimagotipo{assets/Usach P2.png}          % fondo claro
    \usachimagotipoblanco{assets/Usach PB.png}    % fondo oscuro

No editar, recolorear ni recomponer el imagotipo: el MNG lo declara indivisible.

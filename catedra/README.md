# Cátedra

Organización del trabajo de **cátedra** del curso Metodologías de
Investigación Aplicada (13854.0 M-40, 2.º semestre 2026).

## Subcarpetas

| Carpeta              | Contenido                                                                                                               |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| `informacion-usach/` | Material oficial de la plataforma USACH (ejemplos de proyectos, modelos CEI) — por subir. Solo lectura.                 |
| `material/`          | Material de estudio organizado por unidad + glosario + lecturas críticas + registro clase a clase.                      |
| `proyecto/`          | Documentación del proyecto de laboratorio (contenido por confirmar).                                                    |
| `tareas/`            | Entregas evaluadas de cátedra. Una subcarpeta `T<n>-<tema>/` por trabajo (`T1-ejemplo-procesamiento/` es la plantilla). |
| `utilidades/`        | Scripts auxiliares (lectura de Excel/PDF, plantilla LaTeX) — por copiar del repo de laboratorio.                        |

## Trabajos de cátedra

| Trabajo | Tema                                  | Peso |
| ------- | ------------------------------------- | ---- |
| T1      | Ética (seres humanos + fraude/plagio) | 15 % |
| T2      | Mini Review                           | 25 % |
| T3      | Métodos cuantitativos                 | 30 % |
| T4      | Métodos cualitativos                  | 30 % |

Nota de cátedra = `Trabajos × 0,8 + Presentaciones × 0,2`. Todas las
evaluaciones deben ser ≥ 4,0.
